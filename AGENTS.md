# Agent Directives

## Core Principles
- Always respond in Japanese. (回答はすべて日本語で行うこと)
- Be concise and direct. Skip pleasantries and conversational fluff.
- When modifying code, state the reason for changes and the conclusion first.

## Code Standards
- Respect existing project structures and coding conventions.
- Do not leave unnecessary logic, unused variables, or dead code comments.
- Do not add comments to the code unless explicitly instructed.

## Execution Constraints
- Do NOT modify files outside the specified task scope without explicit permission.
